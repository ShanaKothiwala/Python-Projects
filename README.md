# ⚖️ BMI Calculator
 
A simple Python script (in Jupyter Notebook form) that calculates a person's Body Mass Index (BMI) from their weight and height, then classifies the result into a weight category.
 
## 📁 Project Contents
 
| File | Description |
|------|-------------|
| `BMI_Calculator.ipynb` | Jupyter Notebook containing the BMI calculator |
 
## 🧮 How It Works
 
The program:
 
1. Asks for the user's **name**
2. Asks for their **weight in pounds**
3. Asks for their **height in inches**
4. Calculates BMI using the standard imperial formula:
```
   BMI = (weight × 703) / (height²)
```
 
5. Prints the calculated BMI and classifies it into a category:
   
| BMI Range | Category |
|---|---|
| < 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight |
| 24.9 – 29.9 | Overweight |
| 29.9 – 34.9 | Obese |
| 34.9 – 39.9 | Severely obese |
| ≥ 39.9 | Morbidly obese |
